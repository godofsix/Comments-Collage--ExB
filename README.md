# GIS Day Collage Experience Builder Widget

Copy this folder into the Experience Builder Developer Edition widget directory:

`client/your-extensions/widgets/collage`

In Experience Builder, add the widget to the app, select the Survey123 feature layer as its data source, and configure the field names if they differ.

The default fields match the current GISDay service:

- `i_use_gis_to`
- `gis_helped_me_by`
- `name`
- `division`
- `division_other`
- `created_date`

This source requires an Experience Builder Developer Edition project to compile. The hosted ArcGIS Experience Builder does not support uploading arbitrary custom widget source folders.
